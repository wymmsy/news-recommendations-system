# News Recommendation System (Habr)

Веб-приложение на Python, которое собирает статьи с [Habr](https://habr.com), позволяет размечать их вручную (интересно / возможно / неинтересно) и на основе разметки предсказывает, какие из новых статей стоит показать пользователю. Классификация реализована с нуля — наивный байесовский классификатор без использования готовых ML-библиотек для самого алгоритма.

## Как это работает

1. **Сбор статей** (`scraputils.py`) — скрапер на `requests` + `BeautifulSoup` обходит страницы `habr.com/ru/articles/`, извлекает заголовок, автора, ссылку и уровень сложности каждой статьи, умеет переходить по пагинации на несколько страниц вперёд.
2. **Хранение** (`db.py`) — статьи сохраняются в SQLite (`news.db`) через SQLAlchemy ORM; при сохранении отсекаются дубликаты по `habr_id`.
3. **Разметка** — через веб-интерфейс пользователь помечает статьи метками `good` / `maybe` / `never`.
4. **Классификация** (`bayes.py` + `habrnews.py`) — размеченные статьи (заголовок + автор) используются как обучающая выборка для собственной реализации `NaiveBayesClassifier` со сглаживанием Лапласа. Модель обучается, оценивается на отложенной выборке (`sklearn.model_selection.train_test_split`) и затем применяется к неразмеченным статьям, сортируя их по предсказанной релевантности.
5. **Рекомендации** — маршрут `/recommendations` отдельно обучает классификатор и показывает только статьи, предсказанные как `good`.
6. **Веб-интерфейс** (`bottle` + шаблоны `.tpl`) — отображение списков новостей, формы разметки и результатов классификации.

## Стек технологий

- Python
- [Bottle](https://bottlepy.org/) — веб-фреймворк
- SQLAlchemy + SQLite — хранение данных
- BeautifulSoup + requests — скрапинг Habr
- scikit-learn (`train_test_split`) — разбиение на train/test
- Собственная реализация наивного байесовского классификатора
- unittest + unittest.mock + `boddle` — тесты

## Запуск проекта

```bash
git clone https://github.com/wymmsy/news-recommendations-system.git
cd news-recommendations-system
pip install -r requirements.txt
python habrnews.py
```

Приложение поднимется на `http://localhost:8081`. Доступные маршруты:

- `/news` — список неразмеченных статей с формой разметки
- `/add_label/?id=<id>&label=<label>` — проставить метку статье
- `/update_news` — спарсить свежие статьи с Habr и добавить новые в базу
- `/classify` — классифицировать неразмеченные статьи и показать их отсортированными по релевантности
- `/recommendations` — показать только статьи, предсказанные как «интересные»

## Тесты

```bash
python -m unittest test_bayes.py
python -m unittest test_habrnews.py
```

`test_bayes.py` проверяет классификатор на игрушечном наборе предложений и на реальном датасете SMS-спама (точность ожидается не ниже ~98%). `test_habrnews.py` проверяет логику разметки, обновления новостей и сортировки при классификации с помощью моков базы данных.

## Данные

Файл `SMSSpamCollection`, используемый в `test_bayes.py` для проверки классификатора на реальных данных, — это датасет **SMS Spam Collection v.1**, собранный Tiago A. Almeida и José María Gómez Hidalgo и распространяемый свободно для исследовательских целей (с просьбой указывать авторство). Подробное описание и условия использования — в `SMSSpamCollection.README` внутри архива с датасетом. Сам датасет не имеет отношения к статьям Habr и служит только для юнит-теста классификатора.
